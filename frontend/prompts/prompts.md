# Interface com Tailwind

Crie uma interface moderna e responsiva para o frontend Angular usando Tailwind CSS.

Requisitos:
- Layout responsivo.
- Visual moderno com fundo em gradiente escuro.
- Card para criação de tarefa.
- Lista de tarefas em cards.
- Botões com estados hover e disabled.
- Mensagens de sucesso e erro.
- Loading ao criar tarefa.
- Loading ao gerar sugestão com IA.
- Estado vazio quando não houver tarefas.
- Badges para status e prioridade.

# Testes Unitários do Frontend

Crie testes unitários para o componente Angular de tarefas.

Requisitos:
- Testar criação do componente.
- Testar carregamento inicial das tarefas.
- Testar criação de tarefa.
- Testar geração de sugestão com IA.
- Testar conclusão de tarefa.
- Testar exclusão de tarefa.
- Testar validações de título obrigatório.

Usar Jasmine, TestBed e mock do TaskService.
